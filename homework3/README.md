# Gateway и Ledger

Домашнее задание 3. Бюджеты реализованы в сервисе Ledger, в папке `homework3/ledger`.

Команды ниже запускаются из корня репозитория.

## Требования

- Go 1.22 или новее

## Ledger

Сервис печатает `Ledger service started`, загружает бюджеты из `budgets.json`, обновляет их через `SetBudget` и добавляет тестовые транзакции. Транзакция с нулевой суммой отклоняется. Если для категории задан бюджет и новая транзакция его превышает, `AddTransaction` возвращает ошибку `budget exceeded` и не сохраняет транзакцию.

```powershell
cd homework3/ledger
go run .
```

`budgets.json` лежит рядом с программой и читается из текущего каталога. В файле два бюджета: «еда» — 5000 и `transport` — 2000. В `main` лимит `transport` меняется на 1500, и добавляется бюджет `utilities` — 1000.

Ожидаемый результат:

- сохраняются «продукты» и «кафе» (вместе 4700 при лимите 5000), «метро» (400 при лимите 1500) и «электричество» (300 при лимите 1000);
- отклоняются «ресторан» (итог 5200), «такси» (итог 1600), «отопление» (итог 1100) и «пустая операция» (сумма 0);
- в списке транзакций остаются только четыре сохранённые операции.
