# Ledger

Домашнее задание 4. Проверка данных вынесена в интерфейс `Validatable` в сервисе Ledger, папка `homework4/ledger`.

Команды ниже запускаются из корня репозитория.

## Требования

- Go 1.22 или новее

## Ledger

`Transaction` и `Budget` реализуют `Validate() error`. `AddTransaction` и `SetBudget` вызывают эту проверку до записи и не сохраняют некорректные данные. `CheckValid` принимает любой `Validatable` и вызывает `Validate`.

Проверки бюджетов из задания 3 сохранены: транзакция, которая превышает лимит категории, по-прежнему возвращает `budget exceeded` и не попадает в список.

```powershell
cd homework4/ledger
go run .
```

`budgets.json` лежит рядом с программой. В файле два бюджета: «еда» — 5000 и `transport` — 2000. В `main` лимит `transport` меняется на 1500, добавляется бюджет `utilities` — 1000, а бюджет с пустой категорией отклоняется.

Ожидаемый результат:

- `CheckValid` принимает корректные `Transaction` и `Budget` и возвращает ошибку для отрицательной суммы и нулевого лимита;
- сохраняются «продукты», «кафе», «метро» и «электричество»;
- отклоняются «ресторан», «такси», «отопление», нулевая сумма и пустая категория;
- в списке транзакций остаются только четыре сохранённые операции.
